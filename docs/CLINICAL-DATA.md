# CLINICAL-DATA · 临床数据与医学边界（v0.1 草案）

**0 临床审核声明**：本文全部医学内容未经临床审核；阈值、频次、疗程一律【待核】或「以医生安排为准」。

## 内容边界（指南只定内容边界，不转自测或选治疗）

- 病种定义：复发性心包炎＝心包炎症状在无症状间隔（文献口径 4–6 周【待核】）后再次出现。本台只做记录与整理，不做诊断。
- 病程表达：发作—缓解交替；界面只用「发作中第 N 天 / 缓解期第 N 天 / 距上次发作 N 天 / 近 90 天发作次数」这类已记录事实计数，不做严重度分期。
- 化验：CRP、ESR 为主（血常规、心肌酶可登记但不解读）；同屏口径「仅回顾，不解读」「不同方法/机构不合并」「解读归医生」。
- 治疗：NSAID、秋水仙碱、糖皮质激素、IL-1 拮抗剂（anakinra/rilonacept）——界面只登记「医生开了什么、我记了什么」，不出现选药建议、剂量推荐、减量规则；疗程口径【待核】。
- 中国适应证与可及性：IL-1 拮抗剂中国境内可及性与医保状态未知 → 【待核】，不写入任何指引性文案。
- 预后/生存：一律不出现。
