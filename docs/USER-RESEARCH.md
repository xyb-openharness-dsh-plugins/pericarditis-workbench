## 用户画像（改写描述，待访谈验证）

1. **患者本人**：中青年为主，已过首次发病、处于复发与维持随访期。核心任务：记录发作与缓解、跟上化验节奏、管住按次治疗、复诊前整理材料。
2. **照护者/家属**：陪同就诊、帮忙记发作次数与用药；需要知道「哪些情况要联系医生」（只按医生已确认的行动计划原话呈现）。

## 痛点排序假设（无访谈，仅作设计排序依据，不做统计宣称）

1. 发作规律不可见（缓解第几天/距上次多久要心算）→ S1
2. 化验散落多机构、怕方法不可比 → S2
3. 按次治疗（注射/调药）容易漏记 → S3
4. 复诊「不知道该问什么」→ S4
5. 对复发本身的担忧无处安放 → S6

## 与家族既有仓的对照结论

家族内 R2 仓（肢端肥大症、大动脉炎、PBC 等）均为「确诊档案 + 功能与日常 + 并发症筛查 + 医保资源」形态；本台差异：**发作—缓解事件是第一实体**（其余仓多为随访节律型），按次治疗登记与 IL-1 拮抗类新型治疗记录是独立录入线。
