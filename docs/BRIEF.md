# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：复发性心包炎患者及照护者；核心诉求是弄清发作规律、化验趋势与按次治疗记录，复诊时能带着清单与医生对话

场景：反复心包炎发作与缓解交替，患者最关心现在缓解第几天、距上次发作多久、近 90 天发作几次；CRP/ESR 化验单散落多家机构需要长期趋势但不同方法不可比；秋水仙碱日常服药与 IL-1 拮抗按次注射要逐条记录；复发恐惧下需要就诊准备与问题清单（认领 Issue #62，罕见病 #70）

核心流程：
1. 选择本机资料目录并导入化验/超声/病历报告
2. 记录一次发作或缓解事件，核对入库
3. 登记按次治疗（秋水仙碱/IL-1 拮抗/复诊）
4. 查看 CRP/ESR 趋势与发作—缓解区间带
5. 生成复诊准备材料与问题清单

完成结果：得到来源可追溯、可核对的个人病程档案：发作—缓解事件带、CRP/ESR 趋势、按次治疗登记、复诊问题清单与多医院就医信息；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
