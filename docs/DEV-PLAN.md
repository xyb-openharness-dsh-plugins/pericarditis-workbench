认领依据：[Issue #62](https://github.com/xyb-openharness-dsh-plugins/.github/issues/62)（已 claimed）· BACKLOG 罕见病 #70 · R2 非肿瘤慢性病型 · T2

## 一、领取理由

1. **BACKLOG 状态 ⬜ 招募中、无认领 issue、无同名仓**（2026-11-07 核对：open issue 列表 #62 之前无复发性心包炎；org 仓列表无 pericarditis-workbench）。
2. **随访天然结构化**：CRP/ESR 周期性化验、发作—缓解事件、按次治疗登记（NSAID/秋水仙碱/激素/IL-1 拮抗）、心脏超声心包积液随访——与脚手架「档案 + 指标 + 事件」引擎直接对齐。
3. **差异化明显**：家族已有仓覆盖肿瘤、血液病、血管炎（大动脉炎）、肝病（PBC）、消化与呼吸系统；复发性心包炎是首个以「发作—缓解 + 按次治疗 + 炎症指标」为核心的心血管炎症病种。
4. **非肿瘤表达天然匹配**：家族 1.3 节非肿瘤替换表（缓解第 N 天 / 距上次发作 N 天 / 近 90 天发作次数 / 发作—缓解区间带）与本病病程语义一一对应，无分期/线序语义需要剥离。
