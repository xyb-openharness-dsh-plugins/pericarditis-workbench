# DIFF-MATRIX · 差异化矩阵（v0.1）

对移植样板 cervical-workbench 与成熟基准 breast-cancer-workbench v0.4 的全量对照。**一级重名率实测**：M1 末附计数。

| # | 场景 | 本台功能 | 样板/基准对应 | 差异化 | 怎么验 |
| --- | --- | --- | --- | --- | --- |
| D1 | 发作—缓解规律 | 首屏状态卡「缓解期第 N 天/发作中第 N 天 + 距上次发作 N 天 + 近 90 天发作次数」+ 时间线发作—缓解区间带 | 基准用肿瘤 D+N 天数/治疗线序；样板无发作实体 | 一级差异：发作事件是第一实体 | 状态卡与 demo 唯一源联动；禁词扫描 D+N=0 |
| D2 | 炎症化验长期趋势 | CRP/ESR 按方法/机构分组可比线 + 「不同方法不合并」 | 基准是肿瘤标志物口径；样板是 SCC-Ag | 二级差异：可比性分组规则换为炎症指标 | MT03/MT06 量测；跨方法断线 |
| D3 | 按次治疗登记 | 秋水仙碱日常 + IL-1 拮抗按次 + 激素疗程三条登记线，三态保存连续录入 | 基准/样板为线序治疗卡 | 二级差异：按次事件而非治疗线 | 连续录入不清屏；事实层单版本链 |
| D4 | 复发担忧与家庭影响 | 心理与生活影响页（对齐小橙宝 #mind），只记录不评估 | 基准无独立心智线；样板无 | 一级差异：整页线 | 空态给下一步按钮；无评分判定入库 |
| D5 | 心包积液超声随访 | 超声报告登记 + 积液量文字描述归档（不做量级判定） | 样板影像登记 | 三级差异：字段语境化 | 报告表同一来源 ID（MT11） |
| D6 | 就诊准备 | 复诊问题清单 + 多医院就医信息卡 | 家族通用件 | 通用保留 | F6 验收：多医院逐条卡 |

**裁剪项（如实记录，非静默缺失）**：肿瘤五 Tab 中的「治疗线/分期」类页签、35 号试验匹配三子页（理由见 DEV-PLAN §四；M4 数据底座保留）。一级重名率目标 ≤70%，M1 实测后回填：**实测值=（待 M1）**。
