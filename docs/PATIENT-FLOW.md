# PATIENT-FLOW · 患者旅程（v0.1 草案，0 访谈改写句）

旅程按「一次复发周期」展开，与功能线一一对应：

1. **察觉不适 → 记一次发作**（S1）：在「事件」页新增发作记录（开始日期、症状备注 ≤6 字段）。若医生已确认过行动计划，首页行动带呈现医生原话；没有就引导「问医生」，不生成提醒话术。
2. **就医与化验 → 核对入档**（S2/S6）：化验报告导入或手工录入 CRP/ESR，候选逐项核对入库；超声报告文字描述归档，不做积液量判定。
3. **治疗调整 → 按次登记**（S3）：「治疗」页三态保存（保存并继续录入/保存并关闭/取消），连续记录注射与调药，不止一条。
4. **缓解期 → 看规律**（S1/S2）：首页状态卡「缓解期第 N 天 · 距上次发作 N 天 · 近 90 天发作 N 次」；时间线看发作—缓解区间带；一图秀看 CRP 分组趋势。
5. **复诊前 → 带着清单去**（S4/S7）：复诊准备页整理问题清单（每页编辑入口 ≤1），多医院就医信息逐条卡；导出私密过滤。
6. **平时 → 情绪与家人**（S6）：「心理与家庭」页记录担忧与生活影响，只记录不评估，空态给下一步按钮。
7. **任何时候 → 理解疾病**（S5）：顶栏「?」或首页疾病介绍入口打开整页疾病概要四段（DP 模块，primer-data.js 唯一源），每段带来源行与两句固定出口。

回首页：每个一级页导航可达；路径产物可观察（记录 +1 / 文件下载 / 清单条目出现）。
