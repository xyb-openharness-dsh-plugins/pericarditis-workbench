# SCENARIOS · 场景清单（v0.1 草案）

**0 患者访谈声明**：本清单无一手患者引语。下列「场景句」为基于疾病知识的改写描述，不冒充患者原话；每条标注「改写句 · 待访谈验证」。0 临床审核声明：医学表述未经临床审核，阈值均【待核】。

## S1 发作规律（核心线）

- 场景句（改写）：反复发作后，患者最想知道「现在缓解第几天、距上次发作多久、近 90 天发作几次」，用来安排生活与复诊。
- 功能：首屏状态卡（缓解期第 N 天 / 发作中第 N 天 + 距上次发作 N 天 + 近 90 天发作次数，全部为已记录事实的计数，非判定）；时间线发作—缓解区间带。
- 验收：两套合成档案 A/B 切换整页联动不串档；全站无 D+N、无病期线序词；切换后状态卡数字与 demo 唯一源一致。

## S2 化验趋势线

- 场景句（改写）：化验单来自不同医院，CRP/ESR 每次都查，患者想知道趋势但怕「不同方法混着看」。
- 功能：一图秀按方法/单位/机构分组连线 + 「不同方法/机构不合并」口径同屏；指标卡最近值/差值/次数/来源。
- 验收：跨方法断线（MT06）；指标页与一图秀同目录（MT03）；差值不带疗效结论。

## S3 按次治疗线

- 场景句（改写）：秋水仙碱每天吃，复发时可能加激素或 IL-1 拮抗注射，患者想逐条记下来不漏。
- 功能：治疗按次登记（秋水仙碱日常 / IL-1 拮抗按次 / 激素疗程），三态保存按钮，连续多条录入。
- 验收：录入多记录不清屏；事实层单版本链；界面不生成用药建议。

## S4 就诊准备线

- 场景句（改写）：复发次数多了以后，复诊时想不起来该问什么，希望提前整理问题清单和检查材料。
- 功能：复诊问题清单、就医信息多医院卡片、报告原件登记与「最近报告表」。
- 验收：表单 ≤6 字段；显式编辑入口每页 ≤1；医生原话类内容只照抄。

## S5 疾病理解线（疾病概要）

- 场景句（改写）：确诊复发后想一次看懂「这是什么病、有哪些规范资料、治疗全景、新进展」，并知道哪些要问医生。
- 功能：顶栏「?」打开整页疾病概要（36 号四段：定义→医学资料规范和指南情况→治疗全景→发展趋势），数据源 prototypes/v0.2/primer-data.js（DP 模块）。
- 验收：P1–P9 探针全过；面板非弹窗（高度 ≥90% 视口）；趋势段无禁词；每段来源行；「不代表任何一项适合你」「需要问你的医生」两句出口在位。

## S6 心理与家庭影响线

- 场景句（改写）：一次次复发让人担心「会不会一直这样」，家人也想知道能帮上什么。
- 功能：心理与生活影响页（对齐小橙宝 #mind 结构）：担忧记录、生活影响笔记、家人支持事项，只记录不评估。
- 验收：空态给下一步按钮；无情绪评分判定入库。

## S7 资料与隐私线

- 场景句（改写）：病历和报告是私密资料，导出或问 AI 时不想把标记私密的内容带出去。
- 功能：私密三出口过滤（看板摘要预览/导出/AI 上下文），页内「N 条中私密 M 条」。
- 验收：私密记录三出口均不出现；更正=新版本，历史版本自带私密标记。
